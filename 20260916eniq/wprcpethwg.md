# 社区建卡后3个月可以转去大医院吗？

> 更新时间：2026-09-16 (UTC+8)

可以，社区建卡后3个月可以转去大医院。这时候孕妇只需要将社区建的卡，直接带去医院就可以建大卡了。怀孕建卡是孕6周-13+6周内，根据自己的的情况选择一家正规医院进行建卡，建卡的目的是方便孕期做产检及将来分娩做准备。这时候孕妇需要携带身份证等证件做资料的录入以及做第一次全面的产前检查。当然，去医院建卡的时候，大家可以提前了解一下建卡的流程。

## 医院建卡流程

怀孕后的女性，一般在孕12周左右的时候，就需要去你所在的医院建档，然后按照医生规定的时间去医院参加产检。孕妇去医院建档之前，可以提前了解一下以下的建档流程。

- 1. 在孕妇确认怀孕并确定建卡时间后，在建卡当天就应该早早的去医院挂号，这样才能早点检查，因为建卡前，需要孕妇空腹。
- 2. 挂完号后，孕妇就可以到产科门诊室等候的时候，将你的病例卡、填写的表格、挂号纸、小卡一并交给护士，等护士叫到你的名字，然后进去就诊；
- 3. 孕妇进去就诊之后，医生会询问你你的病史，以前是否有过流产等等，然后填上单子，并给你开相关检查单；
- 4. 待医生给你开完检查单后，孕妇或家人就需要及时去缴费，然后做相关检查，检查项目一般包括B超、心电图、测血压、测身高以及抽血等等，建议孕妇前去抽血和做B超，因为抽血和做B超需要空腹，做完这两项检查后，孕妇就可以先去吃点东西垫垫肚子，以免出现低血糖等不良反应；
- 5. 做完相关检查后，孕妇就需要等待拿结果，一般来说早上做的检查，下午就能够拿到结果，待拿到结果后，孕妇就需要去刚才那个医生那里回诊，这时候医生会给你说，你的检查结果，然后给你交代需要注意的事项等，待这些事情做完后，卡也就建完了。

一般来说，社区建卡后3个月可以转去大医院。当然，不同高的医院转卡的时间也是有所不同的，因此孕妇可以提前了解一下，顺便了解一下建卡的流程。
