# 去公立医院给早产儿打一次促肺针多少钱一针？

> 更新时间：2026-09-10 (UTC+8)

早产儿出生时肺部发育尚未完全成熟，难以自主呼吸，需要医生采取措施帮助其促进肺部发育。促肺针就是其中一种常用的治疗方法，通过注射特殊的物质刺激肺泡生长，提高早期新生儿的呼吸能力。很多家长在面对早产儿的时候都会考虑去公立医院给孩子打促肺针，希望能够最大程度地保障孩子的健康。那么，去公立医院给早产儿打一次促肺针多少钱一针呢？

 在选择医院时，家长可以考虑以下几个因素：1. 医院的知名度和声誉。 2. 医院新生儿科的经验和技术水平。 3. 医院的医疗设备和设施是否完善。 4. 医院的服务态度和环境是否舒适。
